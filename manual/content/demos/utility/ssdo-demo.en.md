# 屏幕空间方向性遮蔽 (SSDO)

这个演示展示了如何实现和使用屏幕空间方向性遮蔽（Screen Space Directional Occlusion, SSDO）效果，这是对传统SSAO（屏幕空间环境遮蔽）效果的增强版本，能够提供更真实的间接光照和色彩渗透效果。

## SSDO vs SSAO

SSAO（屏幕空间环境遮蔽）是一种流行的技术，用于模拟环境光被周围几何体遮挡的效果，但它有一个重要的局限性：**它假设环境光是均匀的**，不考虑场景中物体的颜色。

SSDO（屏幕空间方向性遮蔽）通过以下方式改进了这一点：

1. **考虑间接光照**：SSDO不仅计算遮蔽，还考虑了被遮挡点的颜色作为间接光照的贡献
2. **色彩渗透效果**：这使得场景中的彩色物体可以将其颜色"渗透"到周围的表面上
3. **更真实的照明**：结果更接近于全局光照（GI），但计算成本要低得多

对比示例中的SSAO和SSDO，可以明显看到色彩渗透的差异，特别是在彩色球体附近的表面。

## 技术实现

SSDO的核心思想是**将SSAO中被视为"遮挡"的点重新解释为"间接光源"**。

```glsl
// 传统SSAO：这些点只计算遮挡
if (vn < 0.0) {
    occlusion += ...
}

// SSDO：这些点计算遮挡和间接光照贡献
if (vn < 0.0) {
    // 被遮挡 - 获取采样点的颜色作为间接光照
    vec3 sampleColor = texture2D(colorBuffer, coords).rgb;
    
    // 添加间接光贡献
    indirectLight += sampleColor * ...;
    
    // 仍然计算遮挡
    occlusion += ...;
}
```

## 演示控制

本演示允许您交互式地比较SSAO和SSDO效果，并调整各种参数：

### 常规设置
- **效果选择**：在SSAO和SSDO之间切换
- **采样数量**：控制质量和性能
- **环半径**：控制深度采样的螺旋形图案
- **采样半径**：效果的影响范围
- **强度**：整体效果强度
- **偏差**：消除深度不连续性引起的瑕疵

### SSDO特定设置
- **间接光强度**：控制色彩渗透效果的强度
- **间接光距离**：控制色彩渗透的传播距离
- **启用色彩渗透**：切换色彩渗透效果

### 其他功能
- **点击球体**：高亮选择特定球体观察其色彩渗透效果
- **颜色设置**：可以为AO添加自定义颜色
- **调试视图**：可以查看场景法线

## 实现注意事项

实现SSDO时的主要挑战：

1. **需要颜色缓冲**：除了深度和法线缓冲外，SSDO还需要场景颜色缓冲
2. **渲染顺序**：颜色缓冲必须在应用SSDO效果之前更新
3. **采样质量**：间接光计算对噪点更敏感，可能需要更多采样
4. **参数调整**：找到间接光强度和距离的最佳值对于不同场景可能需要调整

## 性能考虑

SSDO比SSAO计算开销更大，性能优化建议：

- 减少采样数量以提高性能
- 在高性能要求的应用中可以降低分辨率
- 考虑使用时间抖动采样来减少噪点
- 对于移动平台，可能需要降低半径和采样数
