# 降雨效果

降雨效果提供了真实的雨天天气模拟，包括动态雨滴、湿润表面、积水反射、雨雾以及闪电等完整的雨天视觉体验。该效果使用多层雨滴渲染技术和物理模拟，可以创建从细雨到暴风雨的各种降雨场景。

## 特点

1. **多层雨滴系统** - 真实的降雨视觉效果
   - 前景、中景、背景多层雨滴渲染
   - 不同大小和速度的雨滴
   - 椭圆形雨滴形状模拟运动模糊
   - 支持雨滴倾斜角度和风向影响

2. **物理准确的雨滴行为** - 基于真实物理的雨滴运动
   - 重力下落效果
   - 风力影响雨滴轨迹
   - 湍流和随机性模拟
   - 不同层次的雨滴速度变化

3. **完整的雨天环境效果** - 丰富的视觉细节
   - 湿润表面效果，增强反射和对比度
   - 积水区域的水面反射和波纹
   - 雨雾效果，模拟空气中的水汽
   - 雨天特有的灰暗色调调整

4. **动态闪电系统** - 暴风雨场景的闪电效果
   - 分支状闪电形状生成
   - 闪电的闪烁和亮度变化
   - 环境照明的动态变化
   - 可控制的闪电频率和强度

5. **灵活的降雨控制** - 全面的参数调节
   - 降雨强度：从毛毛雨到暴雨
   - 雨滴大小和速度控制
   - 风向和风力影响
   - 湿润程度和积水强度调节
   - 雨雾密度控制

## 使用指南

本演示展示了降雨效果在3D场景中的应用：

### 降雨强度预设

使用内置预设快速设置不同强度的降雨：

- **小雨(light)** - 轻柔的细雨
  - 降雨强度：30%
  - 雨滴较小，下落缓慢
  - 轻微的湿润效果
  - 无闪电效果

- **中雨(moderate)** - 正常强度的降雨
  - 降雨强度：60%
  - 中等大小的雨滴
  - 明显的湿润和积水效果
  - 适度的雨雾

- **大雨(heavy)** - 强烈的降雨
  - 降雨强度：80%
  - 较大的雨滴，快速下落
  - 强烈的湿润效果和积水
  - 闪电效果启用

- **暴风雨(storm)** - 最强烈的降雨
  - 降雨强度：100%
  - 最大的雨滴和最快的下落速度
  - 最强的湿润、积水和雨雾效果
  - 频繁的闪电和环境照明变化

### 参数调整

#### 基本降雨参数
- **降雨强度(intensity)** - 控制整体降雨的强度和可见度
- **雨滴速度(rainSpeed)** - 调整雨滴的下落速度
- **雨滴大小(rainSize)** - 控制雨滴的视觉大小
- **雨滴角度(rainAngle)** - 设置雨滴的倾斜角度（度数）
- **雨滴颜色(rainColor)** - 自定义雨滴的颜色

#### 风力效果
- **风向(windDirection)** - 使用2D向量控制风的方向和强度
  - X分量：水平风力（负值向左，正值向右）
  - Y分量：垂直风力（通常设为0）

#### 环境效果
- **湿润程度(wetness)** - 控制表面的湿润效果强度
  - 影响表面反射和对比度
  - 增强材质的视觉质感
- **积水强度(puddleIntensity)** - 控制积水区域的可见度和反射
- **雨雾强度(mistIntensity)** - 调整空气中雨雾的密度

#### 闪电效果
- **启用闪电(enableLighting)** - 开启或关闭闪电效果
- **闪电频率(lightningFrequency)** - 控制闪电出现的频率
- **闪电颜色(lightningColor)** - 设置闪电的RGB颜色

### 实际应用技巧

#### 创建真实的雨天场景
1. 从小雨预设开始，逐步调整到合适的强度
2. 根据场景需要调整风向，创建斜雨效果
3. 增加湿润程度来增强材质的真实感
4. 适度使用雨雾效果增加大气感

#### 营造暴风雨氛围
1. 使用暴风雨预设作为基础
2. 启用闪电效果并调整频率
3. 增加积水强度创建更多反射
4. 结合天空效果创建厚重的云层

#### 性能优化建议
- 在移动设备上减少降雨强度
- 根据场景距离调整雨滴大小
- 在不需要时关闭闪电效果

## 技术细节

降雨效果采用了多种先进的渲染技术：

### 多层雨滴渲染
- **分层策略**：前景大雨滴 + 中景中雨滴 + 背景小雨滴
- **噪声驱动**：使用程序化噪声生成随机雨滴分布
- **运动模拟**：椭圆形变和角度旋转模拟雨滴运动模糊
- **动画系统**：基于时间的连续动画循环

### 物理模拟
- **重力模型**：真实的重力加速度模拟
- **风力计算**：风向对雨滴轨迹的实时影响
- **湍流效果**：使用多频率噪声模拟空气湍流

### 视觉效果处理
- **表面湿润**：通过对比度和反射增强模拟湿润表面
- **积水渲染**：程序化生成积水区域和水面波纹
- **雾气效果**：体积雾渲染模拟雨中的水汽
- **色彩处理**：雨天特有的色调和亮度调整

### 闪电系统
- **分支生成**：程序化生成自然的闪电分支形状
- **动态照明**：实时计算闪电对环境的照明影响
- **时序控制**：随机但可控的闪电出现时机

性能说明：该效果使用GPU优化的多层渲染技术，在现代设备上表现良好。对于低端设备，建议降低降雨强度和禁用闪电效果以获得更好的性能。
