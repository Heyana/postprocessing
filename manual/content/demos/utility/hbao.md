# 基于地平线的环境光遮蔽 (HBAO)

HBAO是一种高级的屏幕空间环境光遮蔽技术，它通过地平线采样计算环境光遮蔽，相比传统的SSAO能提供更精确、更自然的阴影和遮蔽效果，从而显著提升场景的深度感和真实感。

## 主要特性

- **物理准确的遮蔽计算** - 基于地平线角度和余弦权重的采样，提供更逼真的阴影效果
- **高质量边缘** - 在几何边缘和物体交界处产生更自然的遮蔽过渡
- **细节增强** - 在几何细节处提供更精确的阴影，增强深度感知
- **自适应采样** - 根据表面法线和深度变化调整采样，提高效率
- **降噪支持** - 内置降噪功能，消除低采样率下的噪点

## 操作指南

本演示展示了HBAO在3D场景中的应用。您可以通过控制面板调整各种参数来体验不同的效果：

### 基本参数

- **AO距离** - 控制环境光遮蔽的影响范围
- **距离衰减** - 调整遮蔽效果随距离衰减的速率
- **厚度** - 设置遮蔽检测的深度容差
- **偏移量** - 调整遮蔽计算的偏移，避免自遮挡伪影
- **AO强度** - 控制遮蔽效果的整体强度

### 采样设置

- **每像素采样数** - 控制每个像素发射的采样光线数量，影响质量和性能
- **分辨率比例** - 调整效果渲染的分辨率，平衡质量和性能

### 降噪设置

环境光遮蔽通常会产生噪点，特别是在采样率低时。降噪器能够平滑这些噪点而保持边缘细节：

- **降噪迭代次数** - 控制降噪过滤器的应用次数
- **降噪半径** - 设置降噪过滤器的采样范围
- **深度容差** - 调整基于深度的降噪边缘保留
- **法线容差** - 调整基于法线的降噪边缘保留

## HBAO与传统SSAO的区别

HBAO相比传统的SSAO有以下几个主要优势：

1. **更准确的物理模型** - HBAO使用基于物理的余弦加权半球采样，而SSAO通常使用简单的均匀采样
2. **更好的遮蔽过渡** - HBAO在物体交界处产生更平滑自然的遮蔽渐变
3. **更少的伪影** - HBAO减少了SSAO常见的条带状和光晕伪影
4. **更好的细节表现** - 特别是在复杂几何形状和狭窄空间中表现更佳
5. **更好的空间一致性** - 随着视角变化，遮蔽效果更稳定

## 技术原理

HBAO的工作原理基于地平线检测和物理光照模型：

1. **G-Buffer生成** - 首先获取场景的深度和法线信息
2. **地平线采样** - 从每个像素沿着不同方向采样计算"地平线角度"
3. **余弦权重** - 根据表面法线和采样方向的关系计算遮蔽贡献
4. **距离衰减** - 根据距离和深度差异调整遮蔽强度
5. **空间降噪** - 应用智能过滤器平滑结果并保持边缘

## 性能建议

HBAO比传统SSAO计算量更大，以下是一些优化建议：

1. **调整采样数量** - 对于低性能设备，使用8-12的采样数
2. **降低分辨率** - 使用0.5-0.75的分辨率比例可大幅提升性能
3. **平衡降噪设置** - 使用较少的采样但增加降噪迭代次数
4. **调整AO距离** - 减小AO距离可以提高性能，同时保持近处的遮蔽质量

## 集成与使用

HBAO效果可以与其他后处理效果结合使用，特别是：

- **SSGI** - 为全局光照提供精确的局部阴影
- **景深** - 增强景深效果的空间感知
- **色调映射** - 调整最终图像的动态范围和对比度

要将HBAO集成到您的项目中，只需添加：

```javascript
import { HBAOEffect } from 'postprocessing';

// 创建效果
const hbaoEffect = new HBAOEffect(composer, camera, scene, {
  // 基本配置
  aoDistance: 2.0,
  thickness: 0.3,
  power: 2.0,
  
  // 采样设置
  spp: 16
});

// 添加到合成器
composer.addPass(new EffectPass(camera, hbaoEffect));
```
