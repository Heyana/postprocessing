# 体积云和大气散射效果

体积云和大气散射效果提供了一个逼真的天空和大气模拟系统，包括物理精确的体积光渲染、真实的云层体积渲染以及大气散射。这个效果现在还支持夜空、星空和极光效果，让您可以创建完整的昼夜循环天空系统。本效果使用了先进的PBR（基于物理的渲染）方法，基于robobo1221的体积云技术开发。

## 特点

1. **物理精确的大气散射** - 基于真实世界的物理原理
   - 模拟瑞利散射（蓝天）和米氏散射（日出/日落）
   - 精确的太阳位置和光线方向
   - 自然的天空颜色过渡
   - 可调节的天空蓝度增强

2. **真实体积云系统** - 高级云层模拟
   - 基于噪声的真实体积云渲染
   - 多维度云参数控制（数量、密度、尺度、阈值）
   - 支持动态云层运动
   - 云影投射和自阴影

3. **体积光效果** - 真实的大气体积光
   - 通过大气和云层的光线散射
   - 逼真的光轴效果（God rays）
   - 云层对光线的遮蔽和散射

4. **夜空系统** - 完整的夜空渲染
   - 程序化生成的动态星空，支持闪烁效果
   - 自定义月亮位置、大小和亮度
   - 北极光（极光）效果，可自定义颜色和强度
   - 平滑的昼夜过渡

5. **完全可定制** - 广泛的控制参数
   - 太阳和月亮位置（高度角、方位角）
   - 散射系数和强度
   - 米氏散射方向性
   - 云层密度和动画速度
   - 星空密度和亮度
   - 极光颜色和强度

## 使用指南

本演示展示了体积云和大气散射效果在3D场景中的应用：

**日间天空设置：**
- 使用"天空蓝度"调整天空的蓝色饱和度
- 使用"散射强度"调整整体亮度
- 调整"瑞利散射系数"和"米氏散射系数"改变天空色调
- 通过改变"米氏方向性"参数调整日出/日落的光晕大小
- 使用太阳位置控制（高度角、方位角）模拟一天中不同时间的天空

**云层设置：**
- 调整"云层密度"影响云的透明度
- 调整"云层数量"增加或减少云的覆盖率
- 调整"云层尺度"改变云朵的大小和形状
- 调整"云层阈值"控制云边缘的软硬程度
- 开启"云层动画"以获得动态云效果

**夜空设置：**
- 通过降低太阳高度角到地平线以下进入夜晚模式
- 调整"夜空亮度"控制夜晚天空的整体亮度
- 启用"星空"并调整：
  - "星星亮度"控制星光强度
  - "星星密度"控制星空中星星的数量
  - "星星大小"调整星星的视觉大小
- 启用"月亮"并调整月亮的大小、亮度及位置
- 启用"极光"并通过RGB系数控制其颜色和强度

**场景预设：**
- 使用"白天"预设快速设置明亮的日间天空
- 使用"日落"预设创建黄昏场景
- 使用"星空夜景"预设启用有月亮和星星的夜空
- 使用"极光夜景"预设创建带极光的北极夜空

**视图设置：**
- 使用"视场角(FOV)"调整天空渲染的视角范围，让云朵和大气效果更好地匹配相机设置

体积云和大气散射效果适用于：
- 开放世界游戏和模拟
- 建筑可视化和景观渲染
- 日出/日落场景创建
- 夜空和极光场景
- 需要完整昼夜循环天空系统的3D项目

## 技术细节

此效果基于物理大气散射模型和体积云渲染技术，特点包括：

- **分层体积采样**：使用射线步进技术渲染真实的体积云
- **光线散射模拟**：模拟光线在大气和云层中的散射、吸收和投射
- **多重散射近似**：高效模拟多次散射效果，增强体积感
- **高级相位函数**：使用优化的Henyey-Greenstein相位函数计算光散射方向
- **性能优化**：使用自适应采样和智能抖动技术平衡质量和性能
- **程序化星空**：使用分布式噪声算法高效生成星空
- **极光渲染**：基于三角波噪声模拟真实极光波动效果

性能说明：此效果包含复杂的体积渲染计算，在低性能设备上可能需要调整采样步数以获得更好的性能。夜空和极光效果可能会增加额外的渲染负担，可以根据需要启用或禁用。
