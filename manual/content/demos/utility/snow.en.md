# Snow Effect

The snow effect provides a comprehensive winter simulation for your 3D scenes, combining two distinct components: a surface snow overlay and dynamic snowfall particles. This dual approach creates a convincing winter atmosphere with minimal performance impact.

## Features

1. **Surface Snow Overlay** - Intelligently adds snow to upward-facing surfaces
   - Uses depth and normal information to determine where snow should accumulate
   - Higher surfaces receive more snow, creating natural snowline effects
   - Customizable snow amount, brightness, and color

2. **Dynamic Snowfall** - Adds falling snowflakes to create a blizzard effect
   - Adjustable snow density, size, and speed
   - Configurable wind direction for realistic movement
   - Multiple snowflake layers with varying sizes

## Usage Guide

This demonstration showcases the snow effect in a winter scene:

- Adjust the "Snow Overlay" settings to control how snow accumulates on surfaces
- Experiment with the "Snowfall" settings to create gentle snowfall or intense blizzards
- Toggle each effect individually to see their contributions
- Modify wind direction to create different snowfall patterns

The snow effect is particularly useful for:
- Seasonal transitions in games or visualizations
- Winter-themed environments
- Holiday and Christmas scenes
- Creating atmospheric weather conditions
