# 屏幕空间环境光遮蔽 (SSAO)

SSAO（Screen Space Ambient Occlusion）是一种广泛使用的实时渲染技术，它能够在屏幕空间中近似计算环境光遮蔽效果，从而增强3D场景的真实感和深度感。SSAO通过分析深度和法线信息来确定场景中的凹角、缝隙和物体交界处，并在这些区域渲染柔和的阴影。

## 主要特性

- **性能高效** - 直接在屏幕空间工作，不需要预计算
- **动态场景友好** - 适用于动画和运动物体
- **边缘和细节增强** - 提高几何细节的可见度
- **调整灵活** - 可根据不同场景和风格调整参数
- **降噪支持** - 内置降噪功能消除采样噪点

## 操作指南

本演示展示了realism-effects库的SSAO在3D场景中的应用效果。您可以通过控制面板调整各种参数：

### 基本参数

- **AO距离** - 控制环境光遮蔽的影响范围
- **距离衰减** - 调整遮蔽效果随距离的衰减程度
- **厚度** - 设置遮蔽检测的深度容差
- **偏移量** - 调整偏移值避免自遮挡伪影
- **AO强度** - 控制整体遮蔽效果的强度

### 采样设置

- **每像素采样数** - 控制每个像素的采样数量，影响质量和性能
- **分辨率比例** - 调整效果渲染的分辨率，平衡质量和性能

### 降噪设置

SSAO产生的噪点可以通过内置的降噪功能消除：

- **降噪迭代次数** - 控制降噪过滤器应用的次数
- **降噪半径** - 设置降噪过滤范围
- **深度容差** - 调整基于深度的降噪边缘保留能力
- **法线容差** - 调整基于法线的降噪边缘保留能力

## SSAO与HBAO的区别

虽然SSAO和HBAO都是环境光遮蔽技术，但它们有一些关键区别：

1. **计算方法不同** - SSAO基于随机点采样，HBAO使用地平线角度采样
2. **性能要求** - SSAO通常比HBAO计算量更小，适合更广泛的硬件
3. **结果精度** - HBAO产生更准确的物理效果，而SSAO是一种更快的近似
4. **实现复杂度** - SSAO实现相对更简单，更容易适应不同项目

## 技术原理

SSAO的工作原理基于分析场景深度信息：

1. **深度和法线提取** - 获取场景的深度和法线信息
2. **随机采样** - 在每个像素周围的半球空间中随机生成采样点
3. **遮蔽计算** - 通过比较采样点与中心点的深度差来确定遮蔽程度
4. **平滑处理** - 应用空间滤波器消除噪点并平滑结果
5. **与场景混合** - 将遮蔽信息与最终渲染结合

## 性能建议

以下是一些优化SSAO性能的建议：

1. **调整分辨率比例** - 使用0.5-0.75的分辨率比例可以显著提升性能
2. **合理设置采样数** - 8-16个采样点对大多数场景已足够
3. **平衡降噪设置** - 使用较少采样点加上适当的降噪迭代可以获得良好平衡
4. **限制AO距离** - 减小AO距离可提高性能并保持近景质量

## 集成与使用

realism-effects提供的SSAO可以轻松集成到Three.js项目中：

```javascript
import { SSAOEffect } from 'postprocessing';

// 创建效果
const ssaoEffect = new SSAOEffect(composer, camera, scene, {
  // 基本参数
  aoDistance: 2.0,
  power: 2.0,
  bias: 0.05,
  
  // 采样设置
  spp: 16
});

// 添加到合成器
composer.addPass(new EffectPass(camera, ssaoEffect));
```

SSAO可以与其他后处理效果结合使用，特别是与阴影、光照和色调映射效果搭配使用时，可以显著提升场景的视觉品质和深度感。
