# 屏幕空间全局光照 (SSGI)

屏幕空间全局光照是一种后处理技术，通过分析屏幕空间的深度和法线信息，模拟光线在场景中的反弹，从而产生间接照明和反射效果，提升渲染的真实感。

## 主要特性

- **间接光照** - 模拟光线在场景中的多次反弹，使阴影区域获得间接照明
- **反射效果** - 根据表面材质属性呈现逼真的反射效果
- **颜色渗透** - 模拟颜色从一个表面反射到另一个表面的效果
- **基于物理的渲染** - 根据材质的粗糙度和金属度提供不同的反射效果
- **可配置的质量** - 提供多个预设和参数，平衡视觉质量和性能

## 操作指南

本演示展示了 SSGI 在 3D 场景中的应用。您可以通过控制面板调整各种参数来体验不同的效果：

### 基本参数

- **模式** - 切换 SSGI (全局光照) 或 SSR (仅反射) 模式
- **预设** - 选择低/中/高质量预设
- **距离** - 控制光线追踪的最大距离
- **厚度** - 调整光线步进的深度容差

### 降噪设置

SSGI 可能会产生噪点，特别是在低采样率下。降噪器能够减少这些噪点并保持图像质量：

- **降噪迭代次数** - 控制降噪过滤器的运行次数
- **降噪强度** - 调整降噪的总体强度
- **降噪半径** - 设置降噪过滤器的影响范围

### 光源设置

调整场景中的光源，观察 SSGI 如何影响整体照明：

- **灯光颜色** - 改变主光源的颜色
- **主光源强度** - 调整主光源的亮度
- **环境光强度** - 控制环境光的基本亮度

## 技术原理

SSGI 的工作原理基于屏幕空间光线步进技术：

1. **G-Buffer 生成** - 首先生成包含深度、法线、粗糙度等信息的 G-Buffer
2. **光线步进** - 从每个像素发射光线，并在屏幕空间中步进搜索相交点
3. **间接光照采样** - 在相交点采样场景颜色，作为间接光照贡献
4. **时空降噪** - 应用时间和空间过滤器，减少噪点并稳定结果
5. **合成** - 将间接光照与直接光照合成，得到最终效果

## 性能建议

SSGI 是一种计算密集型效果，对硬件要求较高。以下是一些优化建议：

1. **降低分辨率比例** - 使用 0.5 或 0.75 的分辨率比例可大幅提升性能
2. **选择适当预设** - 在低性能设备上使用 "低质量" 预设
3. **调整光线步数** - 减少步数可提高性能，但会降低精度
4. **优化场景** - 减少不必要的复杂几何体和材质

## 集成与使用

SSGI 效果可以与其他后处理效果结合使用，特别是：

- **景深** - 增强景深效果的立体感
- **基于物理的天空** - 提供更真实的天空照明
- **体积雾** - 增强雾气中的光散射效果
- **泛光** - 增强发光物体对周围环境的照明

要将 SSGI 集成到您的项目中，只需添加：

```javascript
import { SSGIEffect } from 'postprocessing';

// 创建效果
const ssgiEffect = new SSGIEffect(composer, scene, camera, {
  // 基本配置
  preset: "medium",
  distance: 10,
  thickness: 10,
  
  // 降噪设置
  denoiseIterations: 2
});

// 添加到合成器
composer.addPass(ssgiEffect.renderPass);
composer.addPass(ssgiEffect);
```
