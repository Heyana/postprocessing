# 选择性虚幻泛光效果

本案例展示了 SelectiveUnrealBloomEffect，它结合了选择性泛光和 UnrealBloomPass 风格的多级模糊效果，提供更好的视觉质量。该效果允许您仅对场景中的特定对象应用泛光效果。

## 特点

1. **选择性泛光应用** - 只对选中的对象应用泛光效果
   - 通过点击对象来切换泛光效果的开启/关闭
   - 支持对象选择的反转
   - 可以忽略背景，只对前景对象应用泛光

2. **UnrealBloomPass 风格的多级模糊** - 更高质量的泛光效果
   - 使用多级下采样和上采样技术
   - 默认启用 mipmapBlur，提供更好的视觉质量
   - 可调节的模糊半径和 MIP 级别
   - 支持抖动以平滑泛光效果

3. **精细的参数控制**
   - 泛光强度控制
   - 亮度阈值和平滑度调整
   - 颜色着色选项
   - 分辨率控制以优化性能
   - 混合模式自定义

4. **交互式选择**
   - 点击场景中的对象可以添加或移除泛光效果
   - 实时预览效果变化
   - 支持多个对象的选择

## 使用方法

1. **添加对象到选择**：点击场景中的对象即可将其添加到泛光选择中
2. **移除对象**：再次点击已选中的对象可以移除其泛光效果
3. **调整参数**：使用右侧控制面板调整泛光强度、半径、级别等参数
4. **反转选择**：勾选"反转选择"选项可以反转当前的选择状态
5. **忽略背景**：勾选"忽略背景"选项可以只对前景对象应用泛光

## 技术说明

SelectiveUnrealBloomEffect 继承自 BloomEffect，并添加了选择性渲染功能。它使用深度掩码技术来识别需要应用泛光的对象，然后对这些对象应用类似 UnrealBloomPass 的多级模糊效果。

默认情况下，该效果启用 mipmapBlur，使用多级下采样和上采样来实现更高质量的泛光效果，这与 Unreal Engine 的泛光实现方式类似。
