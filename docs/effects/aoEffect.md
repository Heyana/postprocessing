# AOEffect 模型筛选功能需求

## 需求背景

在使用SSAO(Screen Space Ambient Occlusion)效果时，当前实现会对场景中所有模型应用AO效果。然而，在某些情况下，需要选择性地对场景中的特定模型排除AO效果的应用。

## 重点

不要尝试在aoEffect的update中做文章 update之前就已经赋予颜色了 不要考虑任何在AoEffect 的update或者render中的方案 太晚了

## 关键观察

当前已经观察到以下情况：

- 即使将AOEffect的update方法提前返回（即禁用了update执行），颜色效果仍然会应用到所有模型
- 这表明AO效果的应用发生在渲染管线的早期阶段，而不仅仅是在update阶段
- 重点是在哪里可以解决这个问题 而不是怎么解决问题 比如在effectpass中的某一步隐藏模型可以是的aopass忽略这个模型

## 功能需求

1. **选择性筛选**: 能够指定某些模型不应用AO效果，同时保持其他模型正常应用AO效果
2. **无缝集成**: 被排除的模型在正常渲染通道(RenderPass)中仍然正常显示
3. **运行时控制**: 能够在运行时动态添加或移除模型的AO效果排除状态
4. **代码修改**: 可以修改代码或者shader

## 技术考量

需要确定以下关键点：

1. 在渲染管线的哪个阶段进行模型筛选才能有效
2. 如何在不影响主渲染通道的情况下控制模型的AO效果应用
