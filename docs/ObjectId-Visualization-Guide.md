# 对象ID可视化功能使用指南

## 🎨 功能概览

对象ID可视化功能现已集成到G-Buffer系统中，提供了两种可视化模式来帮助调试和验证对象标识功能。

## 🚀 如何使用

### 1. 启用对象ID系统
在调试面板中找到 **"对象ID调试"** 部分：
- ✅ 启用 **"启用对象ID"** 开关
- 🔄 点击 **"扫描场景分配ID"** 为所有对象分配唯一ID

### 2. 激活可视化模式

#### 方法A: 使用快捷按钮
在 **"G-Buffer通道快捷切换"** 部分：
- 🆔 点击 **"🆔 对象ID通道"** 按钮

#### 方法B: 使用显示模式选择器
- 📋 在 **"显示模式"** 下拉菜单中选择 **"G-Buffer ObjectId"**

#### 方法C: 使用对象ID专用按钮
在 **"对象ID调试"** 部分：
- 🎭 点击 **"🎭 彩色可视化"** 按钮
- ⬜ 点击 **"⬜ 灰度可视化"** 按钮

### 3. 切换可视化模式
使用 **"可视化模式"** 下拉菜单：
- **彩色模式**: 不同对象显示为不同的鲜艳颜色
- **灰度模式**: 显示原始ID值的灰度表示
- **关闭**: 回到默认SSR效果

## 🎨 可视化效果说明

### 彩色模式 (Colorful)
- 🌈 **HSV色彩环**: 基于对象ID生成不同色相
- 🎯 **高饱和度**: 便于区分不同对象
- ⚫ **黑色背景**: ID=0(背景)显示为黑色
- 🔄 **色彩循环**: ID值较大时颜色会循环

### 灰度模式 (Grayscale)  
- ⬜ **直接映射**: ID值直接映射为亮度
- 📊 **精确显示**: 显示归一化的ID值(0-1)
- 🔍 **调试友好**: 便于精确检查ID分配

## 🔧 着色器实现细节

### HSV到RGB转换
```glsl
vec3 hsv2rgb(vec3 c) {
    vec4 K = vec4(1.0, 2.0 / 3.0, 1.0 / 3.0, 3.0);
    vec3 p = abs(fract(c.xxx + K.xyz) * 6.0 - K.www);
    return c.z * mix(K.xxx, clamp(p - K.xxx, 0.0, 1.0), c.y);
}
```

### 彩色可视化逻辑
```glsl
if (normalizedId < 0.001) {
    // 背景（ID=0）显示为黑色
    gl_FragColor = vec4(0.0, 0.0, 0.0, 1.0);
} else {
    // 使用HSV色相环为不同ID生成不同颜色
    float hue = fract(normalizedId * 10.0);
    vec3 hsvColor = vec3(hue, 0.8, 0.9);
    vec3 rgbColor = hsv2rgb(hsvColor);
    gl_FragColor = vec4(rgbColor, 1.0);
}
```

## 📊 统计信息

当使用对象ID可视化时，控制台会显示统计信息：
- 📈 **分配的ID数量**
- 💾 **内存使用率**
- 🔄 **回收的ID数量**
- 📋 **详细的对象-ID映射表**

## 🔄 循环切换功能

使用 **"循环切换视图模式"** 按钮可以在所有可视化模式之间快速切换：
1. 默认模式 (SSR效果)
2. SSR效果
3. 原始场景
4. 深度通道
5. 法线通道
6. G-Buffer颜色
7. G-Buffer位置
8. **G-Buffer对象ID** 🆔
9. 遮罩通道
10. 调试模式

## 🐛 故障排除

### 对象ID纹理不可用
如果看到黑屏或警告消息：
1. ✅ 确保 **"启用对象ID"** 已开启
2. 🔄 点击 **"扫描场景分配ID"** 重新分配
3. 📊 检查统计信息确认ID已分配

### 颜色显示异常
- 🎨 尝试切换到灰度模式检查原始ID值
- 🔄 重新扫描场景确保ID正确分配
- 📋 查看控制台输出的统计信息

## 💡 使用技巧

1. **调试选择性渲染**: 使用对象ID可视化来验证选择算法
2. **性能测试**: 比较不同ID分配策略的效果
3. **场景分析**: 了解场景中对象的分布和层次
4. **材质调试**: 验证G-Buffer数据的正确性
